# 🚲 AdventureWorks Sales Performance Dashboard

A comprehensive interactive sales dashboard built using **Microsoft Excel** to analyze business performance, track key performance indicators (KPIs), and uncover sales trends across regions and products.

---

## 📊 Project Overview
This project focuses on analyzing sales data for **AdventureWorks**, providing clear insights into revenue generation, product performance, customer distribution, and annual sales trajectories. The dashboard is designed with a clean dark-mode UI to deliver a seamless and engaging user experience.

---

## 🔑 Key Features & KPIs
* **Total Sales:** Tracks overall revenue performance (e.g., $2,927M).
* **Total Orders & AOV:** Monitors total order volume and Average Order Value.
* **Top-Performing Products:** Identifies top 5 products driving sales volume.
* **Sales Person Performance:** Evaluates sales representative metrics.
* **Geographic Insights:** Breaks down customer distribution by territory (Countries/Regions).
* **Time-Series Analysis:** Visualizes trends by Days of the Week and Yearly performance (2011–2014).

---

## 🛠️ Tools & Technologies Used
* **Microsoft Excel:** 
  * Pivot Tables & Pivot Charts for data aggregation.
  * Advanced Formulas & Data Modeling.
  * Interactive Slicers (Product, Due Date, Months) for dynamic filtering.
  * Custom UI Design & Theme Layout.
